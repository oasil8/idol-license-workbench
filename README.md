# IDOL License WORKBENCH

> 게임·연구에 쓰는 자료(코드, 에셋, AI 생성물, 글꼴…)를 넣으면
> **"이 목적으로 써도 되는지"** 와 **"그러려면 무엇을 해야 하는지"** 를 정리해 주는 로컬 웹앱입니다.

- 🖥️ 내 PC에서만 실행됩니다. 프로젝트 파일·메모는 외부로 보내지 않습니다.
- 📄 결과는 화면과 PDF 리포트로 확인합니다.
- ⚖️ 검토를 돕는 기록이며 **법률 의견이나 출시 승인이 아닙니다.**

**▶ 바로 쓰기: https://oasil8.github.io/idol-license-workbench/**

## 두 가지 버전

| | 🌐 링크 버전 | 🖥️ 로컬 버전 |
|---|---|---|
| 시작 | 위 주소를 열기만 하면 됩니다 | Node.js 설치 후 `npm start` |
| 자료 넣기·판정·결과·PDF·백업 | ✅ | ✅ |
| Hugging Face 모델, GitHub·PyPI 저장소 라이선스 조회 | ✅ | ✅ |
| AI 서비스 약관 자동 조회(OpenAI, Meshy 등), 웹 검색으로 출처 찾기 | ❌ 공식 원문을 붙여넣어 분석 | ✅ |
| 데이터 저장 위치 | 이 브라우저 | 이 브라우저 |

링크 버전에서 일부 조회가 안 되는 이유: 브라우저는 보안 규칙(CORS) 때문에 허용하지 않는 사이트의 내용을 읽을 수 없습니다. 로컬 버전은 내 PC의 서버가 대신 읽습니다.
판정에 쓰는 공식 약관·라이선스 기록은 앱에 들어 있어 두 버전 모두 같은 결과를 냅니다.

## 빠른 시작 (로컬 버전)

**필요한 것:** [Node.js 24](https://nodejs.org/) 이상 (Windows 기준. 다른 OS는 [설정](#설정) 참고)

```sh
npm ci        # 처음 한 번
npm start     # 또는 start.cmd 더블클릭
```

브라우저에서 **http://127.0.0.1:4173** 을 엽니다. 종료는 서버 창에서 `Ctrl + C`.

## 사용 순서

| 단계 | 할 일 |
|---|---|
| **① 자료 넣기** | 프로젝트 폴더·파일·기획서를 넣거나, 이름으로 검색해 직접 등록합니다. |
| **② 사용 조건 정하기** | 목적(Steam 출시, 연구, 학회, 기업 납품…)과 상업·배포·수정 여부를 정합니다. 폴더·문서에서 자동으로 찾은 후보가 있으면 실제로 쓰는 것만 고릅니다. |
| **③ 결과 확인** | 맨 위 결론에서 판정 칸을 누르면 자료별 **해야 할 일**이 펼쳐집니다. `리포트 내려받기 · PDF`로 저장합니다. |

### 결과 읽는 법

| 판정 | 뜻 | 할 일 |
|---|---|---|
| 🟢 **사용 가능 (조건부)** | 지금 목적으로 쓸 수 있습니다. | 저작권 표시·고지 같은 표시된 조건을 지킵니다. |
| 🟡 **판단 보류** | 정보가 부족해 아직 판단할 수 없습니다. | 칸을 눌러 나온 정보(라이선스, 플랜, 버전…)를 채웁니다. |
| 🔴 **사용 불가** | 지금 목적과 충돌합니다. 예: 비상업용(NC) 자료를 Steam에서 판매 | 다른 자료로 바꾸거나 별도 허가를 받습니다. |

하나라도 사용 불가면 프로젝트 결론은 **아직 불가**, 보류나 선택 전 자료가 있으면 **판단 보류**입니다.
판정은 실제보다 관대하지 않도록 설계했습니다. 확실하지 않으면 보류합니다.

## 가져오기가 읽는 것

| 분류 | 형식 | 결과 |
|---|---|---|
| 📄 문서 | PDF, DOCX, PPTX, XLSX, HWPX, ODT, RTF, TXT, MD | 글자를 읽어 기획서·피드백에 적힌 도구·서비스·에셋 이름을 후보로 찾습니다. |
| 📜 라이선스 파일 | LICENSE, COPYING, NOTICE, CREDITS, ATTRIBUTION, AUTHORS, THIRD-PARTY-NOTICES, 에셋 팩 README | MIT, Apache, GPL·LGPL·AGPL, BSD, MPL, CC BY 계열, CC0, OFL 등을 인식합니다. |
| 📦 의존성·잠금 파일 | npm, Python, Rust, Go, .NET, Java, vcpkg, SBOM | 선언된 패키지와 실제 설치 버전을 등록합니다. |
| 🎮 엔진 프로젝트 | Unity, Godot, Unreal | 엔진 버전, 패키지, 애드온·플러그인을 등록합니다. |
| 🗜️ zip 에셋 팩 | .zip | 안의 파일을 같은 규칙으로 하나씩 등록합니다. |
| 🎨 미디어·바이너리 | 3D, 이미지, 음원, 영상, 글꼴, AI 모델, dll·jar 등 | 파일명으로 등록하고, 파일 안의 저작권 정보(XMP, 음원 태그)가 있으면 함께 기록합니다. |

- 씬·프리팹·`.meta`처럼 직접 만든 프로젝트 파일은 등록하지 않지만, 형식별 개수를 처리 기록에 남깁니다. 조용히 빠지는 파일은 없습니다.
- 라이선스 표시가 없는 소스 코드는 직접 작성한 코드로 보고 개수만 기록합니다.
- `.git`, `.env`, `.ssh`, `.aws` 경로는 읽지 않습니다.

**읽지 못하는 것:** 스캔 문서의 글자 인식(OCR), 구형 hwp·doc·xls·ppt의 글자, rar·7z 내부. 이런 파일은 "최신 형식으로 저장하거나 풀어서 다시 가져오기" 안내와 함께 등록됩니다.

## 판정 근거

- **오픈소스·CC 라이선스:** 공식 원문을 바탕으로 한 규칙 (규칙 기준일은 결과에 표시)
- **AI 서비스(OpenAI, Claude, Midjourney, Meshy, Tripo, Suno, ElevenLabs…):** 공식 약관에서 확인한 조항 기록. 7일이 지나면 재확인을 안내합니다.
- **에셋 스토어(Unity Asset Store, Sketchfab, Pixabay, Unsplash, Pexels…):** 공식 라이선스 기록
- 목록에 없는 약관은 원문을 직접 넣어 분석하거나, 판단 보류로 남깁니다. 범용 법률 해석기가 아닙니다.

## 데이터와 네트워크

- 프로젝트는 **브라우저 저장 공간**에만 저장됩니다. 다른 PC나 사람에게 옮길 때는 `프로젝트 백업` 또는 `전체 백업 · 기기 이동` 파일을 쓰세요. 주소(포트)가 바뀌면 저장 공간도 달라집니다.
- 서버는 `127.0.0.1`에만 열리며, 외부 연결은 사용자가 누른 **공식 약관 조회·출처 검색**뿐입니다. 이때 자료 이름만 보내고 파일·원문·메모는 보내지 않습니다.
- PDF는 같은 PC의 로컬 서버에서 만듭니다.

## 개발

```sh
npm test      # 자동 테스트 (node --test)
```

| 경로 | 내용 |
|---|---|
| `server.mjs` | 로컬 서버, 공식 약관 조회·PDF API |
| `report-pdf.mjs` | PDF 리포트 (PDFKit) |
| `dist/` | 앱 본체 (빌드 없음). `core.mjs` 판정 규칙, `result-sections.mjs` 결과 화면, `import-files.mjs`·`assignment.mjs` 가져오기 |
| `dist/web-api.mjs`, `dist/lookup.mjs` | 링크 버전에서 서버 대신 브라우저로 처리하는 조회·PDF |
| `tools/build-site.mjs` | 링크 버전 조립 (`.github/workflows/pages.yml`이 main에 푸시될 때 자동 배포) |
| `web/fonts/` | 링크 버전 PDF용 나눔고딕 (SIL OFL 1.1) |
| `tests/` | 테스트 (서비스 약관 원문 사본은 저장소에 없으며, 없으면 해당 테스트는 건너뜀) |

변경 내역은 git 커밋 기록에 있습니다.
