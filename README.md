# IDOL License WORKBENCH

로컬 라이선스 근거 수집·검토 웹앱. 현재 게임이나 사용자 폴더는 자동 검사하지 않습니다.

## v1.4 사용 순서

모바일에서는 자료 목록을 세로 카드로 표시하여 사용 여부와 정보 수정 버튼을 가로 스크롤 없이 이용할 수 있습니다.

1. **자료 넣기**: 파일·폴더를 선택하거나 서비스·모델 이름으로 검색합니다. 자료는 현재 프로젝트에 추가됩니다. 별도 작업은 먼저 새 프로젝트를 만드세요.
2. **실제 사용할 것 선택**: 자동 탐지한 자료는 ‘선택 전’입니다. 실제 사용 / 대안 보관 / 사용 안 함을 선택하고 버전·플랜·출처 등 정보를 보완합니다. 사용 목적을 고르면 추천 체크값이 적용되며 이후 직접 변경할 수 있습니다.
3. **결과 확인**: 실제 사용하는 자료만 판정합니다. 선택 전 자료가 남거나 필수 조건이 누락되면 전체 결론을 보류합니다. 각 자료의 결론·조건·출처·원문을 한 곳에서 확인하고 PDF 리포트로 저장합니다. 원문은 앱에서 보존하며 PDF에는 핵심 근거만 포함합니다.

기존 직접 등록 자료는 실제 사용으로 유지합니다. 기존 문서 추출 후보는 선택 전으로 분류하며 삭제하지 않습니다. 대안·사용 안 함도 프로젝트와 JSON 백업에 남습니다. 저장 공간 부족이나 문서 추출 실패 시 가져오기 전체를 취소하고 기존 상태를 유지합니다.

## 문서 가져오기

TXT/MD, PDF, DOCX, PPTX에서 텍스트를 추출합니다. LICENSE.pdf나 LICENSE.docx도 문서 추출기로 읽고 라이선스 자료로 등록합니다. 추출 원문·위치를 보관하지만 다른 파일에 그 라이선스를 자동 적용하지 않습니다. 일반 문서에서 찾은 도구 이름은 사용 여부를 확정하지 않은 후보입니다.

문서 최대 20개·합계 60MB, 파일당 텍스트 200,000자·전체 500,000자 제한이 있습니다. PDF/DOCX 최대 10MB, PPTX 최대 30MB, PDF/PPTX 최대 150페이지입니다. OCR과 외부 LLM 연결은 없습니다. 이미지 속 글자와 발표자 노트는 분석하지 않습니다. AI 약관은 항목에서 조회하거나 텍스트·파일로 직접 등록하세요. 업로드 직후 자동으로 외부 조회하지 않습니다.

## 결과와 근거

허용 여부에 실제 영향을 주는 버전·플랜·적용 범위가 빠지면 판단을 보류합니다. 고정된 오픈소스 라이선스의 단순 버전 미기록이나 별도 권리 확인만으로 전체 결과를 보류하지 않습니다. 원문 확인 체크는 사용자가 직접 확인한 기록이며 자동 허가가 아닙니다. 출처 확인일·적용 범위·근거 문구와 사용자 입력을 구분합니다.

`official-sources.mjs`는 2026-10-15에 공개된 공식 원문에서 직접 확인한 조항의 범위·위치·요약을 담은 공통 근거 목록입니다. 특정 사용자의 과제 파일이나 프로젝트는 포함하지 않습니다. 자동 조회가 막힌 사이트의 서버 오류 기록과 이 공개 문서 검토 기록은 서로 구분합니다. 근거 목록의 기록도 7일이 지나면 최신 원문을 재확인하도록 표시하며, 오래된 대조 규칙으로 새 충돌 판정을 만들지 않습니다. 예를 들어 Tripo의 정확한 출력물/무료 플랜/상업 목적이 확인된 경우 최신 검토 범위 내에서 충돌을 표시하지만, 플랜이 미정이면 판단 보류입니다. Hunyuan3D 2.0과 Cosmos 등은 버전·사용 지역·구성에 따라 계약이 달라질 수 있으므로 서비스 이름만으로 허용 여부를 확정하지 않습니다.

범용 웹페이지의 약관을 LLM이 실시간으로 모두 해석하는 기능은 없습니다. 지원하지 않는 서비스·기업/API 계약·과거 생성물·특정 국가 적용·제3자 권리는 원문과 실제 이용 조건을 추가로 확인해야 합니다. 공개 공유 전 이 근거 목록의 최신성도 검토해야 합니다. 로컬 프로젝트는 브라우저 저장 공간에 있으며, 공유할 소스 폴더에 자동으로 포함되지 않습니다.

## 실행

Node.js 24 이상에서 최초 `npm ci` 후 `npm start` 또는 `start.cmd` 실행 후 http://127.0.0.1:4173 접속. 종료는 서버 창에서 Ctrl+C.
API 키는 필요 없습니다. 문서 파서 의존성은 package-lock.json에 고정되어 있습니다. AI 약관 조회 기능은 공식 외부 사이트에 연결합니다. 프로젝트 파일·소스·메모는 외부로 전송하지 않습니다. 포트를 바꾸면 브라우저 저장 공간도 달라집니다.

## 사용

1. 프로젝트를 만들고 사용 목적과 상업·배포·수정·네트워크 조건을 지정합니다.
2. 폴더/파일을 직접 선택합니다. 모델은 이름만 등록되며 원본은 수정하거나 전송하지 않습니다.
3. 항목을 열어 버전, 라이선스, 근거 URL, 구매/플랜/생성일, 별도 권리를 기록합니다.
4. 원문과 적용 범위를 직접 확인한 경우만 확인 표시를 합니다.
5. 리포트에서 상용 결론과 현재 사용 목적 결과, 출처 링크를 확인합니다.
6. 프로젝트 JSON으로 백업·복원하고 HTML 리포트를 내보냅니다. 한글 인코딩(UTF-8)을 명시하고, PDF 발췌문과 문서 추출 원문은 접어서 표시합니다. 브라우저에서 읽거나 인쇄할 수 있습니다.

## 결론의 의미

- 사용 가능 (조건부): 등록한 라이선스 근거와 현재 조건에서 일반 허가가 확인되며, 표시된 의무를 이행해야 합니다.
- 현재 조건으로 사용 불가: NC 상업 사용, Editorial 게임 사용, ND 변형물 배포 등 충돌 조건이 있습니다. 별도 허가가 있으면 재검토가 가능합니다.
- 판단 보류: 적용 라이선스·계약·범위 등 허용 여부를 결정할 핵심 정보가 부족합니다. 상표·초상·입력 자료 등 별도 권리 확인은 계약상 결과와 구분해 표시합니다.

상용 결론은 선택한 배포·수정·네트워크 조건을 유지하고 상업 목적을 true로 평가합니다. 연구 모드에서도 별도로 표시됩니다. 폴더 스캔 결과는 자동으로 확인 완료 처리하지 않습니다. 조건부 결론도 권리 보유 사실이나 의무 이행을 자동 검증한 것이 아닙니다.

## 지원과 한계

package.json 의존성 선언(라이선스 미확인), package-lock v1/v2/v3, requirements 텍스트(라이선스 미확인), SPDX/CycloneDX JSON, LICENSE/COPYING/NOTICE의 일부 문구, 코드의 SPDX 헤더를 읽습니다. AND/OR/WITH는 수동 검토로 유지합니다. 모델·이미지·음원은 파일명만 등록합니다. 외부 패키지 설치나 레지스트리 조회는 하지 않습니다. 동일 라이브러리라도 근거 파일이 다르면 별도 항목이며, 하위 폴더 LICENSE가 다른 에셋에 자동 적용되지 않습니다.

파일당 2MB, 읽은 텍스트 전체 30MB, 선택 10,000개, 항목 5,000개, 프로젝트 50개 제한. 실패·제외·한도는 탐지 기록에 표시합니다. .git/.env/.ssh/.aws 경로는 제외하지만 사용자가 선택한 소스 텍스트 내 민감정보 여부까지 판별하지 않습니다. 폴더 스캔에서는 원문 텍스트 자체를 저장하지 않으며 추출한 이름·경로·라이선스·메모는 localStorage에 저장합니다. 브라우저 데이터를 지우면 사라지므로 백업을 권장합니다. 링크 클릭 시 해당 사이트로 이동합니다.

규칙 기준일 2026-10-14. 원문 링크는 앱의 사용법·판정 기준 탭에 있습니다. 공식 문서 조회는 아래 지원 범위에서 가능합니다. 코드 표절 탐지, 바이너리 분석, 자동 법률 판정은 하지 않습니다. 학회·기업·국가별 정책 및 계약은 별도 검토 대상입니다.

서버는 127.0.0.1에만 바인딩되며 정해진 정적 앱 파일만 제공합니다. 브라우저는 같은 로컬 서버에만 API 요청을 보냅니다. 서버는 허용 목록의 공식 HTTPS 호스트만 조회하며 임의 URL, 다른 Origin, 크기 초과 요청을 거부합니다.


## v1.1 — 최신 AI 약관과 프로젝트 관리

- AI 서비스·모델 추가 → 서비스·플랜·검토 대상 선택 → 최신 약관 조회 → 기록 저장.
- OpenAI/ChatGPT 개인용, Anthropic/Claude 개인용, Meshy, Tripo의 현재 공개 문서에서 알려진 핵심 권리 조항을 추출합니다. 기업/API 계약과 지원하지 않는 약관은 판단 보류입니다.
- Hugging Face는 공개 모델 ID(owner/model)로 선언 라이선스, 모델 리비전, 저장소 수정일을 조회합니다. 모델 가중치의 선언 라이선스를 생성 결과물에 자동 적용하지 않습니다. 모델 게시자 권한과 원본 LICENSE는 직접 확인해야 합니다.
- 확인 시각(KST), 마지막 시도, 공식 링크, 문서 날짜(추출 가능할 때), 짧은 근거 문구를 저장하고 리포트에도 포함합니다. 문서 날짜가 없으면 조회 날짜로 대체하지 않습니다.
- 조회 시 문서 본문에서 핵심 문구를 찾는 규칙 기반 점검이며 문서 전체를 해석하는 LLM 서비스가 아닙니다. 접근 제한(403), 타임아웃, 문구 변경, 미지원 플랜은 판단 보류입니다. 과거 생성물에 당시 어떤 약관이 적용됐는지 자동 확정하지 않습니다.
- 약관의 상용 허가와 항목의 입력·제3자 권리는 구분합니다. 제3자 권리가 미확인이면 최종 결론은 보류합니다. 서비스/플랜/대상 변경, 7일 경과, 백업에서 불러온 조회 기록은 재조회가 필요합니다.
- 등록한 AI 약관 새로 확인 버튼은 현재 프로젝트에서 실제 사용으로 선택한 지원 서비스 항목을 갱신합니다. 동일 요청은 한 번의 일괄 작업 안에서 공유합니다. 시간 예약·백그라운드 모니터링은 없습니다.
- 프로젝트 관리에서 열기·이름 변경·삭제·복원이 가능합니다. 삭제는 휴지통 이동입니다. 동일한 내용의 기존 중복은 휴지통으로 옮기며 내용이 다른 프로젝트는 보존합니다. 샘플은 재클릭해도 기존 것을 엽니다.
- 서버 재시작은 실행 창 Ctrl+C 후 npm start. 기존 v1 프로젝트 저장 키를 유지하므로 기존 브라우저에서 새로고침하면 기록을 유지합니다.

## 직접 입력 약관과 화면 사용법

자료 등록·점검은 입력과 수정, 결과·리포트는 결론과 근거 조회/내보내기, 사용법·판정 기준은 사용 순서와 지원 범위 안내입니다.

AI 항목에서 약관 직접 입력을 펼쳐 전체 원문을 붙여넣거나 UTF-8 TXT/MD(200KB 이하)를 가져오세요. HTTPS 출처와 확인 날짜(KST), 적용 범위 확인 후 입력 약관 분석 → 기록 저장을 누릅니다. PDF·Word(.docx)는 파일 선택으로 텍스트를 추출합니다. 원문은 브라우저에 보관되며 JSON 백업에도 포함됩니다. 자동 일괄 조회는 직접 입력 기록을 건너뜁니다. 직접 입력도 7일 이후 재검토가 필요하며 JSON 복원 기록은 재분석해야 합니다. 알려진 조항을 찾는 규칙 분석이므로 임의 계약·다른 언어·기업/API 계약은 판단 보류일 수 있습니다. 문서의 진위·최신성·누락은 검증하지 않습니다.


## 문서 추출 및 근거 위치

PDF.js(Apache-2.0)와 Mammoth(BSD-2-Clause)의 브라우저 라이브러리를 로컬 서버에서 제공합니다. 외부 CDN이나 문서 업로드 서버를 사용하지 않습니다. PDF·DOCX 최대 10MB, PDF 150페이지, 텍스트 200,000자, 문단 5,000개, 추출 시간 30초 제한입니다. DOCX는 압축 해제 크기 20MB 이하로 사전 검사합니다. TXT·MD는 UTF-8 200KB 이하입니다.

근거 문구 옆 버튼을 누르면 저장된 추출 텍스트에서 PDF 페이지 또는 Word 추출 문단을 열어 강조합니다. 원본 PDF 화면이나 Word 편집 화면을 렌더링하는 기능은 아닙니다. 추출 후 직접 텍스트를 수정하면 이전 페이지·문단 위치는 무효화되고 입력 원문 위치로 표시합니다. 원본 바이너리는 저장하지 않으며 추출 텍스트와 위치만 JSON 백업에 보관합니다. 실패하면 기존 입력을 유지합니다. 스캔 OCR, 구형 .doc, 암호 해제, 문서 내 이미지/서식 해석은 지원하지 않습니다. 다단·표·텍스트 상자의 읽기 순서와 누락 여부는 분석 전에 확인해야 합니다. PDF에서 텍스트 없는 페이지를 발견하면 부분 문서를 통과시키지 않고 추출을 중단합니다.

개발 의존성 점검: Mammoth의 CLI용 argparse → sprintf-js에는 npm audit의 중간 등급 경고가 있습니다. 앱은 해당 CLI를 호출하지 않으며 제공하는 mammoth.browser.min.js에는 이 CLI 의존성이 포함되지 않습니다. 의존성을 업데이트할 때 다시 점검하세요.

## 목록 밖 이름의 무료 웹 검색

항목 편집에서 이름 또는 AI 서비스 이름을 입력하고 **공식 출처 자동 찾기**를 누릅니다. DuckDuckGo 공개 HTML 검색으로 최대 6개의 링크를 찾아 **검색 후보 · 확인 전**으로 보여줍니다. API 키나 유료 검색 서비스는 사용하지 않습니다. 자동 조회는 10초 간격이며 동일 검색 결과는 서버 메모리에 최대 10분간 보관합니다.

검색 서비스에는 이름과 ‘official website terms license’ 검색어만 전달합니다. 파일·추출 원문·메모는 전송하지 않습니다. 자동 검색은 클릭했을 때만 실행합니다. ‘직접 Google 검색’은 Google에서 같은 이름으로 검색하는 별도 링크입니다.

검색 순위나 제목에 official이 있다는 이유로 공식성을 확정하지 않습니다. 제3자·동명이인·유사 도메인이 포함될 수 있습니다. 후보는 클릭·주소 복사가 가능하고, 검토 내용 저장 후 새로고침·JSON 백업·HTML 리포트에서도 후보 상태와 검색어·검색일이 유지됩니다. 라이선스나 확인 체크를 자동 변경하지 않습니다. 원문·권리자·적용 버전 등을 직접 확인한 뒤 기존 근거 입력/약관 입력에서 검토 내용을 기록하세요.
