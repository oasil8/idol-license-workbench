IDOL License WORKBENCH v1.4 — 노트북 실행 및 개발 인계 (2026-10-15 KST)

1. ZIP을 노트북의 작업 폴더에 압축 해제합니다.
2. Node.js 24 이상을 설치합니다. 터미널에서 node --version 으로 확인합니다.
3. package.json이 있는 폴더에서 npm ci 를 실행합니다. 최초 의존성 설치에는 인터넷이 필요합니다.
4. npm start 실행 후 http://127.0.0.1:4173/ 에 접속합니다. Windows에서는 설치 후 start.cmd 실행도 가능합니다.
5. 상단 백업 가져오기에서 기존 PC에서 전체 백업 · 기기 이동으로 내려받은 JSON을 선택합니다.
   기존 프로젝트를 삭제하지 않고 병합합니다. 휴지통도 포함되어 있습니다.
   AI 약관 확인 기록은 가져온 기록으로 표시되며 자동 재조회 또는 직접 입력 재분석 후 판정에 반영됩니다.
6. 작업을 마치면 전체 백업 · 기기 이동으로 새 백업을 보관하세요.

브라우저 기록은 PC 사이에 자동 동기화되지 않습니다. http://localhost 와 http://127.0.0.1 도 저장소가 다릅니다.
4173 주소의 서버가 이미 실행 중이면 기존 서버 창에서 Ctrl+C로 종료하고 이 폴더의 서버를 실행하세요. 기존 데이터를 계속 보려면 같은 브라우저와 같은 주소를 사용하세요.
백업은 작성 당시 스냅샷이며 이후 PC에서 한 수정은 포함하지 않습니다. 이 ZIP은 앱 소스와 합성·공식 원문 기반 테스트 자료를 포함합니다. 사용자 프로젝트는 포함하지 않습니다. 사용자 프로젝트는 기존 PC에서 별도로 전체 백업하세요.

이 폴더의 HANDOFF.txt와 README.md를 읽고 License Workbench 웹앱 개발을 이어가 주세요.

구조
- server.mjs: loopback 정적 서버, 공식 약관 API (허용 호스트만 조회)

- dist/app.mjs, index.html, style.css: UI와 브라우저 저장
- dist/core.mjs: 라이선스 규칙과 프로젝트 검증

- dist/extract-worker.mjs, extract-file.mjs, document-text.mjs: 브라우저 PDF/DOCX 추출, 원문 강조
- dist/backup.mjs: 전체 백업 검증
- tests/: npm test 로 검증

현재 UI
등록 화면은 자료/근거 입력 상태, 리포트는 같은 자료의 상용 판정을 표시합니다.
프로젝트 전체 결론은 리포트에만 있습니다. AI 입력창은 검토 대상 → 약관 확인 → 출처와 추가 권리 확인 순서입니다.

범위와 한계

스캔 OCR과 구형 .doc는 지원하지 않습니다. PDF/DOCX 서식 대신 추출 텍스트에서 근거를 강조합니다.
공식 사이트 접근이 막히면 원문 입력을 사용합니다. 원문의 최신성/진위와 제3자 권리는 별도 확인이 필요합니다.
샘플/체험 프로젝트는 합성 테스트이며 실제 출시 허가가 아닙니다.
v1.2의 PDF/DOCX 추출과 원문 강조는 브라우저 검증 이력이 있습니다. v1.4 화면 검증 상태는 VALIDATION.txt를 확인하세요.
